# 廣島五天四夜｜GitHub Pages 靜態網站

## 發佈方式
1. 在 GitHub 建立一個新的 repository（例如 `hiroshima-trip`）。
2. 將 `index.html` 上傳到 repository 根目錄。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
6. 等待 GitHub Pages 部署完成，網站網址通常為：
   `https://你的GitHub帳號.github.io/hiroshima-trip/`

此網站為純 HTML/CSS，不需要 Node.js、框架或建置流程。
